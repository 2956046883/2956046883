## 🔬 科研与项目 | Research & Projects
<!-- 项目卡片样式 -->
<div style="border: 2px solid #00BFFF; border-radius: 10px; padding: 15px; margin-bottom: 20px; background-color: rgba(0,191,255,0.05);">
  <h3>🏆 Secret Sharing on Random Geometric Graphs</h3>
  <p><strong>IEEE ISIT 2026 Accepted | 第一作者 | 2025.09-2026.01</strong></p>
  <ul>
    <li><strong>项目背景</strong>：传统图秘密共享方案在大规模复杂网络中存储开销随网络密度激增，信息率锐减</li>
    <li><strong>核心贡献</strong>：提出<strong>移位网格分解(SGD)框架</strong>，利用RGG局部团特性将全局非结构化拓扑分解为可处理的局部结构</li>
    <li><strong>突破性成果</strong>：
      <ul>
        <li>将信息率从 <code>1/O(n)</code> 提升至<strong>常数级 O(1)</strong>，实现存储开销与网络规模完全解耦</li>
        <li>构建几何概率模型，推导边存活率闭式解并证明其渐近收敛性</li>
        <li>量化信息率与拓扑保真的权衡关系，明确存储效率的边丢失代价</li>
      </ul>
    </li>
  </ul>
</div>

  <p><strong>项目负责人 | 2024.10-2025.02</strong></p>

    <li><strong>核心贡献</strong>：设计"感知-决策-控制"一体化架构，提出<strong>低频全局决策+高频局部执行</strong>并行计算方案</li>
